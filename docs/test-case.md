## 0. 測試說明

- 每筆案例皆可獨立執行，欄位「結果」請填 **PASS / FAIL**，FAIL 請在「備註」記錄實際現象。
- 標示 **[P0]** 為核心流程，必過；**[P1]** 為次要功能；**[P2]** 為邊界與例外。
- 「裝置」欄：D=桌機瀏覽器、M=行動裝置、B=後端/資料層。

### 測試環境

| 項目 | 值 |
|------|-----|
| 前端啟動 | `npm run dev` → `http://localhost:5173/ai-quiz-app/` |

## 1. 環境前置檢查（部署 / 設定）

這幾項是本系統最常見的失敗點，正式測功能前必須先全數通過。

| 編號 | 裝置 | 檢查項目 | 步驟 | 預期結果 | 結果 | 備註 |
|------|------|----------|------|----------|------|------|
| ENV-01 | B | `.env` 編碼正確 | 用 VS Code 開 `.env`，看右下角編碼 | 顯示 **UTF-8**（非 UTF-16）；`VITE_GAS_URL` 有完整 `/exec` 結尾 | | Vite 只讀 UTF-8，UTF-16 會讀不到變數 |
| ENV-02 | B | GAS 已正確部署 | 瀏覽器直接開 `GAS_URL?action=getActiveQuestion` | 回傳 JSON（或導向 `googleusercontent.com/.../echo`），**非**「找不到指令碼函式 doGet」 | | 失敗代表程式未 `clasp push` + `clasp deploy` |
| ENV-03 | B | 部署存取權為「任何人」 | 用無痕視窗（未登入 Google）開上述網址 | 仍能取得 JSON，不需登入 | | 綁公司網域會擋外部學員 |
| ENV-04 | B | `questions` 表頭正確 | 開 Google Sheets `questions` 第 1 列 | 欄位完全等於：`id, text, optionA, optionB, optionC, optionD, correctAnswer, status, createdAt, updatedAt` | | 名稱逐字相符，大小寫不可錯 |
| ENV-05 | B | `answers` 表頭正確 | 開 Google Sheets `answers` 第 1 列 | 欄位完全等於：`id, questionId, sessionId, answer, timestamp` | | 是 `questionId` 不是 `question_id` |
| ENV-06 | D | 前端能連到後端 | 啟動 dev server，開學員頁 | 不出現「網路連線中斷」；顯示題目或「目前沒有開放的題目」 | | 改完 `.env` 需重啟 dev server |
